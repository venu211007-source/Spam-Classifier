# Spam Email Classifier

A machine learning model that classifies SMS messages as spam or not spam.

## Dataset
SMS Spam Collection Dataset from Kaggle (5,572 messages).

## How to Run
1. Clone this repo
2. Install dependencies: pip install -r requirements.txt
3. Run: python spam_classifier.py

## Model
Naive Bayes classifier with CountVectorizer for text preprocessing.

## Result
Accuracy: 97.8% on test data.

## Libraries
pandas, scikit-learn
